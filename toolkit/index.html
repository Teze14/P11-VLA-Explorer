MODEL CARD & SCIENTIFIC SCOPE

Know what
the model can claim.

What runs here

A frozen, pretrained CLIP ViT-B/32 vision–language model compares image regions and text. It runs through quantized ONNX models in your browser. You do not need a Python environment for this interface.

The action module is a visible mathematical rule: combine region centers using their relative weights, then point from the chosen origin toward that target.

This is a simplified VLA teaching pipeline. It is not OpenVLA, SmolVLA, a learned manipulation policy, or a calibrated explanation of robot behavior.

Three kinds of evidence

  • Learned: image and text embeddings from pretrained CLIP.
  • Computed: cosine scores, softmax weights, weighted target, displayed timings.
  • Designed: region grid, action gain, visualization, and synthetic example scene.

What a true VLA adds

A robot-trained VLA predicts actions from observations and instructions, often with robot state and an action sequence. Those outputs have an embodiment-specific meaning, such as joint positions.

Our companion SmolVLA notebook shows the integration route. The notebook has to be run with compatible observations; its existence is not evidence that a robot policy has been evaluated.

Limitations worth testing

  • Crops lose global context and may cut objects in half.
  • CLIP is not trained to obey arbitrary movement instructions.
  • Softmax always distributes weight, even when the target is absent.
  • Several objects may produce a weighted target in empty space.
  • Faster cached updates are different from a cold model load.
